PDF Tool 便携版 使用说明
================================

这个文件夹里就是完整的程序，目标电脑不需要安装 Python，也不需要装任何运行库。

一、怎么装
    1. 把整个压缩包拷到目标电脑。
    2. 解压到一个普通目录，例如  D:\PDF Tool\  或  桌面\PDF Tool\。
    3. 双击里面的  PDF Tool.exe  就能用。

    注意：必须整个文件夹一起拷。只拿 PDF Tool.exe 一个文件是打不开的，
    旁边的 _internal 文件夹装着全部运行库，删了就废。
    也建议不要放进 C:\Program Files\，那里不让写备份目录。

    第一次打开时，Windows 可能弹蓝框"已保护你的电脑"：
    点 更多信息 → 仍要运行 即可。
    有些杀毒软件会拦打包出来的 exe，选"允许"或把该文件夹加入白名单。

二、怎么用
    1. 把要处理的 PDF 直接拖进窗口（或点"选择文件"多选）。
    2. 左边勾要做的处理：去页码 / 改比例 / 改尺寸 / 旋转 / 去扫描瑕疵 / 去页眉Logo，
       勾多项就是按顺序组合执行；电子签章在处理中保留。
    3. 默认勾着"替换源文件"：成品直接覆盖回原文件，
       被覆盖的原件会先存进程序目录下的  backup\  文件夹，随时能退回去。
    4. 不想覆盖就取消这个勾，成品落在  PDF输出  文件夹里，原文件不动。
    5. 点右上角 X 关窗口时，会先问一句怎么处理：
       · 退出程序（默认选中）—— 彻底关掉，右下角不留小图标；
       · 收进托盘 —— 只关窗口，正在跑的批量任务继续在后台走，
         回来方法：双击右下角小图标，或右键选「显示窗口」。
       下面那个「不再提示」勾上以后就不再问，直接按你选的做。
       想改主意：主界面「高级设置」里勾回「关闭时先问我（退出 / 收进托盘）」。

三、几个文件放哪
    程序目录\backup\                 替换源文件时存下来的原件
    %APPDATA%\PDF Tool\settings.json  记住的界面选项（下次打开还是这些设置）
    开始菜单 / 桌面\PDF Tool.lnk      首次运行自动创建的快捷方式

四、系统要求
    Windows 10 或 Windows 11，64 位。
    32 位系统和 Windows 7/8 用不了这个包。
    1080p、2K 屏都能用：系统显示缩放 100%~200% 时，字号和窗口会跟着实际像素放大，
    窗口高度不会超出屏幕可用区域（内容多就滚轮滚），也不会被任务栏切掉一截。

五、出问题怎么判断
    · 双击没反应：多半是只拷了 exe、没带 _internal 文件夹，重新解压即可。
    · 拖不进文件但可以点按钮选：这是拖拽组件没起来，不影响其他功能，
      把整个文件夹重新解压一次一般就好。
    · 字看着发虚：跑一次 Windows 自带的 ClearType 调谐器（Win+R 输入  cttune  回车，
      照着提示挑最清楚的一档）。界面文字用的是微软雅黑 UI，字号按屏幕真实像素取整，
      正常情况下不会再被系统位图拉伸。
    · 想去页码但没去掉：扫描件和文字版走的是两套判定，把出问题的文件
      留着，方便回来说清楚是哪一页。
